# آکادمی شوالیه | Knight Academy

سامانه‌ی آموزشی خصوصی پایه‌ی پنجم با رابط فارسی و راست‌به‌چپ، الهام‌گرفته از تم تیره و طلایی.

## وضعیت پروژه

این مخزن هنوز نسخه‌ی آزمایشی است و تا تکمیل اتصال Supabase، تنظیم سیاست‌های امنیتی و آزمون نقش‌ها نباید برای اطلاعات واقعی دانش‌آموزان استفاده شود.

## امکانات هدف

- حساب کاربری دانش‌آموز، معلم، مدیر و سازنده
- تأیید حساب‌های تازه‌ثبت‌نام‌شده پیش از دسترسی
- درس‌ها و فایل‌های آموزشی برای ریاضی، فارسی، مطالعات اجتماعی، قرآن و هدیه‌های آسمانی
- فضای خصوصی فایل‌ها در Supabase Storage
- کارت تلاش و تبدیل هر ۱۰ کارت معلم به یک لوح تقدیر
- پنل مدیریت و دستیار هوشمند آموزشی

## معماری

- رابط کاربری ایستا: قابل میزبانی روی GitHub Pages
- احراز هویت، پایگاه داده و فایل‌ها: Supabase
- کلید عمومی Supabase (Publishable/anon) در رابط کاربری قابل استفاده است؛ کلیدهای Secret و service_role هرگز نباید در فایل‌های عمومی یا کد مرورگر قرار بگیرند.
- کلید سرویس هوش مصنوعی باید فقط در محیط سرور یا Supabase Edge Function نگهداری شود.

## امنیت و حریم خصوصی

- عمومی بودن این مخزن فقط به معنی قابل مشاهده بودن کد است؛ اطلاعات کاربران و فایل‌های آموزشی خصوصی نباید در GitHub ذخیره شوند.
- دسترسی واقعی باید با Row Level Security (RLS) و Storage Policies در Supabase کنترل شود؛ مخفی‌کردن دکمه‌ها در رابط کاربری به‌تنهایی امنیت ایجاد نمی‌کند.
- ارتقای نقش به مدیر یا سازنده نباید از طریق ورودی ثبت‌نام یا تغییر مستقیم پروفایل امکان‌پذیر باشد.
- پیش از انتشار عمومی، سیاست‌های RLS، ثبت‌نام، تأیید حساب، بارگذاری و دریافت فایل باید با حساب‌های آزمایشی جداگانه بررسی شوند.

## راه‌اندازی

تنظیمات پروژه‌ی Supabase هنوز باید در محیط انتشار وارد و اعتبارسنجی شوند. هیچ رمز عبور یا کلید محرمانه‌ای را در این مخزن commit نکنید.

## درس‌ها

محتوا باید از پنل مجاز معلم/مدیر بارگذاری شود و از فضای ذخیره‌سازی خصوصی ارائه گردد؛ تا زمان تکمیل این بخش، درس‌ها و فایل‌ها ممکن است در دسترس نباشند.
